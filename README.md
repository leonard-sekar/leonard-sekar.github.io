## // FEATURES

- **ASCII portrait** — image-driven canvas rendering with cursor glow and tap ripples across the hero.
- **Dark / light themes** — remembers the selected theme in browser storage.
- **Responsive layout** — adapts navigation, content, and the portrait to different screen sizes.
- **Motion-aware interactions** — animated reveals, heading decode effect, pointer-responsive panels, and custom cursor; respects reduced-motion preferences.
- **Portfolio sections** — about, skills, projects, AI assistant, and contact.
- **Embedded AI assistant** — Streamlit-hosted chat, with a direct link available from the assistant section.
- **Lightweight static site** — no package installation, build step, or frontend framework required.

## // RUN LOCALLY

No dependency installation is needed. Open `index.html` in a browser, or use a local static server such as the **Live Server** extension in VS Code:

1. Open this folder in VS Code.
2. Start Live Server from `index.html`.
3. Visit the local URL it opens.

The Google Fonts and embedded AI assistant need network access. The assistant itself is a separate Streamlit deployment.
